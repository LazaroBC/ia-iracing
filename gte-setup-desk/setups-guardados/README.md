# Setups guardados (exportados)

Aquí van los `.json` que exportas desde el botón **Exportar** de la app
(panel de histórico). A diferencia del resto de `.json` del proyecto,
estos SÍ se versionan en Git — es tu copia de seguridad real de los
setups guardados.

Sugerencia de nombre: `<coche>-<circuito>-<fecha>.json`, por ejemplo
`porsche-monza-2026-07-31.json`.
